# LitMatch

Открыть библиотеку: **https://1nrei.github.io/**

250 произведений, каждое с полным русским и английским текстом. В разделе «Подбор» нажмите «Все 250», выберите книгу и язык RU/EN. Доступны категории, поиск, оглавление, закладки и сохранение позиции чтения.

Возраст читателя задаётся в квизе или настройках чтения. Отметки 6+, 12+, 16+ и 18+ — предварительные редакционные рекомендации LitMatch, а не экспертная классификация изданий. Для книг 18+ требуется отдельная галочка; она не проверяет личность.

Профиль и история хранятся только в текущем браузере. Синхронизации между устройствами нет. При первом открытии загружается весь HTML, около 27 МБ. Для чтения нужен современный браузер с поддержкой DecompressionStream.

Для автономного чтения сохраните файл index.html и откройте его в браузере. Весь корпус включён в файл; ссылки на источники и внешний словарь требуют интернета.
